# Soundboard

Ein schnelles Android-Soundboard für eine private Gameshow.

## Sounds hinzufügen

1. Eine MP3-Datei nach `assets/audio/` kopieren.
2. Die App neu bauen oder vollständig neu starten.
3. Der Sound erscheint automatisch als Button im Soundboard.

Beispiel: `assets/audio/applaus.mp3` wird automatisch als Button **Applaus** angezeigt.

Die App erkennt derzeit `.mp3`, `.wav`, `.m4a` und `.ogg`. Es sind keine einzelnen Asset-Einträge und keine Dart-Code-Änderungen je Sound nötig.
